# Learning Lab 🌟

A free, customisable educational web app for children.

## Features

- 8 maths challenge levels, with adaptive or fixed difficulty
- Reading comprehension with audio assistance
- Science, logic, general knowledge and coding basics
- Learning progress dashboard
- Optional virtual rewards
- Installable Progressive Web App (PWA)
- Offline-friendly learning activities

## Parent Settings

Families can customise:

- Student nickname and age (5–16)
- School year or stage
- Maths difficulty and reading practice
- Virtual rewards on or off
- Maths, reading and weekly reward amounts
- Monthly reward limit
- Currency: GBP, USD, EUR or NGN

Age does not automatically determine learning ability.

Settings are stored locally in the browser and remain saved after refresh.

## Getting Started

Open the hosted website in a modern browser.

To install, use your browser's Add to Home Screen or Install App option.

## Privacy

- No account or password required
- No analytics or tracking
- No cloud synchronisation
- Progress and settings stay in the browser
- Progress can be exported for personal backup

Clearing browser data may erase saved progress.

Parent Settings are not PIN-protected. Anyone using the same browser can change them.

## Rewards

Rewards are virtual learning incentives, not real-money payments. Parents can customise amounts and limits or disable rewards entirely.

Changing currency does not convert previously earned balances.

## Technology

HTML, CSS and JavaScript.

No paid API or external dependencies required.

## Disclaimer

Learning scores are informal practice indicators, not formal educational assessments. Parents should supervise children's use.
